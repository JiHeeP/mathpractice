## 2. 만든 것 (반 보스 + 막타)
| 파일 | 하는 일 |
|---|---|
| `js/game.js` | 계산만. 처음 통과 1, 잔타격 0.3(그날 합계 10문제 되는 순간, 하루 한 번), 체력 = base × 단계 계수, 막타 판정 `resolveKills` |
| `js/db.js` | `getGame/setGame`(classes/{code}/game/state, 교사만), `getBoss`(wallet 문서 합산), wallet/{번호} 요약 쓰기, `saveKill` |
| `js/session.js` | 결과 화면 "문어 대장에게 −1.3", 막타 안내 |
| `js/app.js` | 학생 화면 보스 체력 띠 |
| `js/teacher.js`, `index.html` | 교사 설정 '🐙 반 보스' 칸: 학생 수·빼는 번호·켜기/끄기·1단계부터 새로 시작·막타 표 |
| `firestore.rules` | `game/{id}`(교사만 쓰기), `wallet/{id}`(학생 기기 쓰기, 코인·아이템 자리 미리 열어 둠) — **더하기만** |
| `tools/test-game.js` | 계산 검사 |

핵심 설계
- 데미지는 저장하지 않고 학생 자기 기록(results)에서 다시 계산한다. wallet은 반 합계를 싸게 읽기 위한 요약이다.
- '새로 시작' = game/state의 `startTs`를 바꾼다. 그 뒤 기록만 센다. 연습·도전 기록은 건드리지 않는다.
- 막타: `wallet.kills[{s, ts, next}]`. 같은 학생이 두 번 연속 막타면 그 보스 보상은 막타 바로 앞에 깎은 학생이 고른다.
- 게임 읽기·쓰기가 실패해도 도전과 기록 저장은 그대로 된다(게임 칸만 빠짐).

## 3. 선생님 결정 (다시 묻지 말 것)
- 1단계 체력 = 학생 수 × 2. 학생 수는 17(18·99 제외).
- 통과 못 한 날에도 잔타격·작은 코인 준다. 잔타격 조건은 '그날 합계 10문제+'.
- 보스는 주마다 초기화하지 않음. 단계 계수 1, 1.1, 1.3, 1.6, 2, 2.5, 3, 4(교사가 고칠 수 있게).
- 보스 쓰러지면 교실 보상. 막타 학생이 고름, 두 번 연속이면 다음 사람.
- 학년 말: 기록만 백업, 게임은 초기화. 0회 학생은 교실에서 같이 열기.
- 내 섬 지도는 안 함. 펫 보류. 랜덤 상자 있음. 꾸미면 데미지 배수(상한 ×2.5).
- 그림 누가 만들지는 미정 → 처음엔 단순한 도형·이모지.

## 5. 원칙과 6단계 확인 (요약)
원칙: 한 번에 하나 · 기본 꺼짐 · 수학이 먼저 · 기록 고치지 않음 · 다시 계산 가능 · 코인은 한 묶음 처리 · 숫자는 `js/game.js` 한 곳 · 검사 먼저 · 번호만(이름 저장 금지, students 읽지 않음, 18·99 집계 제외) · 머지는 선생님 "머지"로만.

확인: ① 자동 검사 ② 연습 모드(LOCAL1) 시나리오 캡처 ③ 미리보기에서 99번 한 판 + Claude가 서버 값 대조 ④ 머지 ⑤ 운영 99번 ⑥ 다음 등교일 뒤 대조. 통과 못 하면 다음 단계 안 감.

G1 ③ 순서
1. 선생님 PC: `firebase deploy --only firestore:rules` (더하기만이라 운영 화면 영향 없음)
2. 미리보기 교사 설정 → 🐙 반 보스 → 학생 수 17, 빼는 번호 `18` → 켜기 (시험 중엔 99 빼지 않음)
3. 99번으로 기초 한 판 10문제+ → 결과 화면 "−0.3" 또는 "−1.3" 확인
4. Claude: `game/state`, `wallet/99`, 99번 기록을 읽기 전용으로 대조
5. "머지" → 운영 99번 → 빼는 번호 `18, 99`로 고치고 "1단계부터 새로 시작"
