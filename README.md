# 분수 연산 마스터

초등 분수·소수 연산 연습 웹앱 (22레벨). 배포 주소: https://mathpractice-five.vercel.app/ Google Apps Script(스프레드시트 + `google.script.run`)로 만들었던
「수학 연산 마스터」를 **정적 웹앱 + Firebase Firestore** 로 옮긴 것입니다.

- 빌드 도구 없음 — HTML/CSS/JS 파일을 그대로 Firebase Hosting에 올리면 끝
- 외부 CDN 의존 없음 — Tailwind와 Chart.js를 `vendor/` 에 직접 담아 학교 네트워크에서도 안전
- Firebase 설정 전에는 **로컬 모드**(localStorage)로 그대로 돌아가므로 바로 열어볼 수 있음

## 1. 레벨 구성 (전 22레벨)

다음 레벨의 *도전 연습*을 열려면 이전 레벨 도전에서 **오답 2개 이하**(과정형 레벨은 **1개 이하**),
그리고 **시간 감점 없이**(제한시간의 80% 이내) 완주해야 합니다.
(자유 연습은 언제나 열려 있습니다. 기준은 `js/levels.js` 의 `allowedWrong` 로 조절합니다.)

| 그룹 | 레벨 | 내용 | 방식 | 만점 |
|---|---|---|---|---|
| 🎨 개념 | L1 | 분수 개념 — 그림 보고 맞히기 (대분수 포함) | 4지선다 | 90 |
| | L2 | 소수 개념 — 그림 보고 맞히기 (1보다 큰 소수 포함) | 4지선다 | 95 |
| 🔁 변환 | L3 | 가분수 → 대분수 | 4지선다 | 100 |
| | L4 | 대분수 → 가분수 | 4지선다 | 105 |
| | L5 | 분수 → 소수 (세 자리까지 · 대분수 포함) | 4지선다 | 110 |
| | L6 | 소수 → 분수 (기약분수 · 대분수 포함) | 4지선다 | 115 |
| 🍕 동분모 | L7 | 분모가 같은 분수의 덧셈 | 4지선다 | 120 |
| | L8 | 분모가 같은 분수의 뺄셈 | 4지선다 | 125 |
| 🔗 통분 | L9 | 최소공배수 구하기 | 4지선다 | 130 |
| | L10 | 분수 통분하기 | 4지선다 | 135 |
| ➕➖ 이분모 | L11 | 진분수 덧셈, 합이 1을 넘게 | **과정** | 140 |
| | L12 | 〃 | 4지선다 | 145 |
| | L13 | 진분수 뺄셈 | **과정** | 150 |
| | L14 | 〃 | 4지선다 | 155 |
| 🎯 대분수 | L15 | 대분수의 덧셈 | **과정** | 160 |
| | L16 | 〃 | 4지선다 | 165 |
| | L17 | 대분수의 뺄셈 | **과정** | 170 |
| | L18 | 〃 | 4지선다 | 175 |
| 🔢 소수 | L19 | 소수의 덧셈 (두 자리까지) | 4지선다 | 180 |
| | L20 | 소수의 뺄셈 (두 자리까지) | 4지선다 | 185 |
| | L21 | 소수의 덧셈 (자릿수 다름) | 4지선다 | 190 |
| | L22 | 소수의 뺄셈 (자릿수 다름) | 4지선다 | 195 |

### 과정(단계 풀이)이 물어보는 것

L11 이분모 덧셈을 예로 들면: 분모가 같은가? → 최소공배수 → 통분 ① ② →
분자끼리 계산 → 약분 확인·실행 → **답이 1을 넘으므로 대분수로 나타내기**.
답할 때마다 위쪽 풀이판이 한 줄씩 채워지고, 틀려도 정답을 보여준 뒤 진행합니다.

### 4지선다의 오답 보기

각 유형의 '흔한 실수'가 오답으로 나옵니다 — 약분 안 한 답, 분모끼리 더한 답,
소수점 자리를 안 맞추고 더한 값, 몫·나머지를 뒤바꾼 대분수, 3/4 → 0.34 식 표기 등.
값은 맞지만 형태가 틀린 보기(예: 기약이 아닌 분수, 최소공배수가 아닌 통분)를 고르면
무엇이 아쉬운지 따로 알려 줍니다.

### 채점 규칙

- **분수 답은 기약분수만 정답**, 1을 넘는 답은 **대분수 형태만 정답**입니다.
- L1(그림 개념)만 예외 — 그림이 보여 주는 표기 그대로(3/6)가 정답입니다.
- L1·L2의 40%는 "꽉 채운 도형 몇 개 + 부분 도형"으로 대분수(1 1/2)나 1보다 큰 소수(1.69)를 묻습니다.
  이때 가분수로 읽은 보기(3/2)를 고르면 대분수로 나타내라고 알려 줍니다.
- **도전 모드 4지선다에서 오답을 고르면 시간이 10초 깎입니다** (찍기 방지).
- 과정형의 정답·오답 피드백 대기는 짧게(0.6~1.8초) 잡고, 그만큼 제한시간을 넉넉히 두었습니다.

## 2. 실행

### 로컬에서 바로 보기 (Firebase 없이)

```bash
npm install
npm start          # http://127.0.0.1:8080
```

`js/firebase-config.js` 가 예시값 그대로면 **로컬 모드**로 동작합니다.
예시 학생 3명이 자동으로 만들어지고 기록은 그 브라우저에만 저장됩니다.

### 파일 하나로 묶어 나눠 주기 (서버·인터넷 없이)

```bash
node tools/build-single-file.js     # → dist/분수연산마스터.html
```

CSS와 JS를 전부 집어넣은 HTML 한 개가 나옵니다. 더블클릭하면 바로 열리므로
USB로 나눠 주거나 인터넷이 안 되는 교실에서 쓰기 좋습니다.
(이 파일은 항상 로컬 모드라 기록이 그 컴퓨터에만 남습니다.)

### Firebase에 올리기 (진짜 '사이트'를 만드는 단계)

배포하면 `https://<프로젝트이름>.web.app` 주소가 생깁니다. 그 전까지는 사이트 주소가 없습니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고
   **Firestore Database**를 (프로덕션 모드로) 켭니다.
2. 프로젝트 설정 → 내 앱 → 웹 앱 추가 → 설정값을 복사해
   `js/firebase-config.js` 에 붙여넣습니다.
3. `.firebaserc.example` 를 `.firebaserc` 로 복사하고 프로젝트 ID를 채웁니다.
4. 배포:

```bash
npm install -g firebase-tools
firebase login
firebase deploy --only firestore:rules,hosting
```

## 3. Firestore 데이터 구조

| 컬렉션 | 문서 | 필드 |
|---|---|---|
| `students` | 학생 1명 | `number`(문자열), `name`, `pinHash`(선택) |
| `results` | 연습 1회 | `studentNo`, `level`, `mode`, `correct`, `incorrect`, `accuracyPct`, `durationSec`, `timeLimit`, `isOvertime`, `resultStatus`, `score`, `ts`, `dateKey` |
| `accessLogs` | 접속 1회 | `studentNo`, `ts`, `sessionId` |
| `config` | `app` | `teacherPinHash`(선택) |

### 학생 명단 넣기

Firestore 콘솔에서 `students` 컬렉션에 문서를 하나씩 추가합니다.
문서 ID는 학번으로 두는 것이 편합니다.

```
students/1   { number: "1", name: "김철수", pinHash: "" }
students/2   { number: "2", name: "이영희", pinHash: "9f2c..." }
```

- `pinHash` 가 비어 있으면 그 학생은 비밀번호 없이 바로 들어갑니다.
- 해시값은 `tools/pin-hash.html` 을 브라우저로 열어 만드세요.

### 교사 PIN

기본값은 `js/firebase-config.js` 의 `DEFAULT_TEACHER_PIN` (`490800`) 입니다.
바꾸려면 `config/app` 문서에 `teacherPinHash` 를 넣으세요 (역시 `tools/pin-hash.html` 사용).

### 개인 링크

`https://<프로젝트>.web.app/?student=3` 처럼 열면 그 학생으로 바로 들어갑니다.
`?view=teacher` 로 열면 교사 로그인 화면으로 바로 갑니다.

## 4. ⚠️ 보안에 대해 (꼭 읽어 주세요)

이 앱은 요청하신 대로 **Firebase 인증 없이** 동작합니다. 그래서 다음이 사실입니다.

- 앱 URL을 아는 사람은 누구나 **학생 명단과 모든 점수 기록을 읽을 수 있습니다.**
- 점수는 브라우저에서 계산해 저장하므로, 마음먹으면 **점수를 위조할 수 있습니다.**
- 학생 PIN·교사 PIN은 해시로 저장해도 자릿수가 짧아 알아낼 수 있습니다.
  PIN은 "다른 친구 이름으로 잘못 들어가는 것"을 막는 정도로만 생각하세요.
- 교사 대시보드 PIN도 마찬가지로 화면을 가려 줄 뿐, 데이터를 지켜 주지는 못합니다.

`firestore.rules` 는 인증 없이 할 수 있는 만큼은 막아 두었습니다.

- 기록은 **추가만** 가능 — 이미 저장된 점수를 고치거나 지울 수 없음
- 학생 명단과 설정은 **읽기 전용** — 콘솔에서만 수정
- 기록 문서의 필드 종류·개수·값 범위를 검사해 아무 데이터나 못 넣게 함

나중에 이 부분이 신경 쓰이면 **익명 인증(Anonymous Auth)** 을 켜고 규칙을
`request.auth != null` 로 좁히는 것이 가장 적은 노력으로 크게 나아지는 방법입니다.
점수 위조까지 막으려면 Cloud Functions에서 점수를 계산해야 하고, 이때는 Blaze 요금제가 필요합니다.
