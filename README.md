# 분수 연산 마스터

초등 분수 연산 연습 웹앱. Google Apps Script(스프레드시트 + `google.script.run`)로 만들었던
「수학 연산 마스터」를 **정적 웹앱 + Firebase Firestore** 로 옮긴 것입니다.

- 빌드 도구 없음 — HTML/CSS/JS 파일을 그대로 Firebase Hosting에 올리면 끝
- Firebase 설정 전에는 **로컬 모드**(localStorage)로 그대로 돌아가므로 바로 열어볼 수 있음

---

## 1. 레벨 구성 (전 15레벨)

이전 레벨에서 **만점**을 받아야 다음 레벨의 *도전 연습*이 열립니다.
(자유 연습은 언제나 열려 있습니다.)

| 그룹 | 레벨 | 내용 | 방식 | 만점 |
|---|---|---|---|---|
| ✖️➗ 정수 | L1 | 두자리수 × 한자리수 | 세로셈 단계 풀이 | 90 |
| | L2 | 두자리수 ÷ 한자리수 | 세로셈 단계 풀이 | 95 |
| | L3 | 정수 곱셈·나눗셈 종합 | 4지선다 | 100 |
| 🍕 동분모 | L4 | 분모가 같은 분수의 덧셈 | 단계 풀이 | 105 |
| | L5 | 분모가 같은 분수의 뺄셈 | 단계 풀이 | 110 |
| | L6 | 동분모 종합 | 4지선다 | 115 |
| 🔗 통분 | L7 | 분모가 다른 분수의 덧셈 | 단계 풀이 | 120 |
| | L8 | 분모가 다른 분수의 뺄셈 | 단계 풀이 | 125 |
| | L9 | 이분모 종합 | 4지선다 | 130 |
| ⚡ 곱셈·나눗셈 | L10 | 분수 × 분수 | 단계 풀이 | 135 |
| | L11 | 분수 ÷ 분수 | 단계 풀이 | 140 |
| | L12 | 분수 곱셈·나눗셈 종합 | 4지선다 | 145 |
| 🎯 대분수 | L13 | 가분수 ↔ 대분수 | 단계 풀이 | 150 |
| | L14 | 대분수의 덧셈·뺄셈 | 단계 풀이 | 155 |
| | L15 | 대분수의 곱셈·나눗셈 | 단계 풀이 | 160 |

### 단계 풀이가 물어보는 것

통분이 필요한 덧셈을 예로 들면:

1. 두 분수의 분모가 같나요? (예/아니오)
2. 두 분모의 **최소공배수**는?
3. 앞 분수를 그 분모로 통분하면 분자는?
4. 뒤 분수를 통분하면 분자는?
5. 분자끼리 계산하면?
6. 이 분수를 **약분할 수 있나요?** → 최대공약수는? → 약분하면?
7. (대분수 레벨) 대분수로 고치면?

답할 때마다 위쪽 **풀이판**이 한 줄씩 채워집니다. 틀려도 정답을 알려주고 다음 단계로 넘어가므로
풀이가 중간에 막히지 않습니다.

### 채점 규칙

- **답은 기약분수만 정답으로 인정합니다.** 값이 맞아도 약분하지 않으면 오답이고,
  "값은 맞아요! 하지만 기약분수로 약분해야 합니다" 라고 알려 줍니다.
- 대분수 레벨(L13~L15)은 **정수 · 분자 · 분모 칸**에 각각 넣어야 하며, 분수 부분도 기약이어야 합니다.
- 4지선다에서도 '약분하지 않은 답'이 오답 보기로 자주 등장합니다.

### 점수

만점에서 시작해 오답 1개당 2점 감점, 제한시간의 80%를 넘기면 최대 10점까지 서서히 감점,
제한시간을 넘기면 추가 감점합니다.

**자유 연습은 점수가 없습니다** (`score: null`). 다만 "몇 문제를 언제 풀었는지"는 기록으로 남아
교사가 연습량을 볼 수 있고, 점수가 없으므로 랭킹이나 다음 레벨 해금에는 영향을 주지 않습니다.

## 2. 실행

### 로컬에서 바로 보기 (Firebase 없이)

```bash
npx http-server -p 8080 -c-1
# http://127.0.0.1:8080 접속
```

`js/firebase-config.js` 가 예시값 그대로면 **로컬 모드**로 동작합니다.
예시 학생 3명이 자동으로 만들어지고 기록은 그 브라우저에만 저장됩니다.
(`file://` 로 열어도 되지만, 로컬 서버로 여는 편이 안전합니다.)

### Firebase에 올리기

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만들고
   **Firestore Database**를 (프로덕션 모드로) 켭니다.
2. 프로젝트 설정 → 내 앱 → 웹 앱 추가 → 설정값을 복사해
   `js/firebase-config.js` 에 붙여넣습니다.
3. `.firebaserc.example` 를 `.firebaserc` 로 복사하고 프로젝트 ID를 채웁니다.
4. 배포:

```bash
npm install -g firebase-tools
firebase login
firebase deploy --only firestore:rules,hosting
```

## 3. Firestore 데이터 구조

| 컬렉션 | 문서 | 필드 |
|---|---|---|
| `students` | 학생 1명 | `number`(문자열), `name`, `pinHash`(선택) |
| `results` | 연습 1회 | `studentNo`, `level`, `mode`, `correct`, `incorrect`, `accuracyPct`, `durationSec`, `timeLimit`, `isOvertime`, `resultStatus`, `score`, `ts`, `dateKey` |
| `accessLogs` | 접속 1회 | `studentNo`, `ts`, `sessionId` |
| `config` | `app` | `teacherPinHash`(선택) |

### 학생 명단 넣기

Firestore 콘솔에서 `students` 컬렉션에 문서를 하나씩 추가합니다.
문서 ID는 학번으로 두는 것이 편합니다.

```
students/1   { number: "1", name: "김철수", pinHash: "" }
students/2   { number: "2", name: "이영희", pinHash: "9f2c..." }
```

- `pinHash` 가 비어 있으면 그 학생은 비밀번호 없이 바로 들어갑니다.
- 해시값은 `tools/pin-hash.html` 을 브라우저로 열어 만드세요.

### 교사 PIN

기본값은 `js/firebase-config.js` 의 `DEFAULT_TEACHER_PIN` (`490800`) 입니다.
바꾸려면 `config/app` 문서에 `teacherPinHash` 를 넣으세요 (역시 `tools/pin-hash.html` 사용).

### 개인 링크

`https://<프로젝트>.web.app/?student=3` 처럼 열면 그 학생으로 바로 들어갑니다.
`?view=teacher` 로 열면 교사 로그인 화면으로 바로 갑니다.

## 4. ⚠️ 보안에 대해 (꼭 읽어 주세요)

이 앱은 요청하신 대로 **Firebase 인증 없이** 동작합니다. 그래서 다음이 사실입니다.

- 앱 URL을 아는 사람은 누구나 **학생 명단과 모든 점수 기록을 읽을 수 있습니다.**
- 점수는 브라우저에서 계산해 저장하므로, 마음먹으면 **점수를 위조할 수 있습니다.**
- 학생 PIN·교사 PIN은 해시로 저장해도 자릿수가 짧아 알아낼 수 있습니다.
  PIN은 "다른 친구 이름으로 잘못 들어가는 것"을 막는 정도로만 생각하세요.
- 교사 대시보드 PIN도 마찬가지로 화면을 가려 줄 뿐, 데이터를 지켜 주지는 못합니다.

`firestore.rules` 는 인증 없이 할 수 있는 만큼은 막아 두었습니다.

- 기록은 **추가만** 가능 — 이미 저장된 점수를 고치거나 지울 수 없음
- 학생 명단과 설정은 **읽기 전용** — 콘솔에서만 수정
- 기록 문서의 필드 종류·개수·값 범위를 검사해 아무 데이터나 못 넣게 함

나중에 이 부분이 신경 쓰이면 **익명 인증(Anonymous Auth)** 을 켜고 규칙을
`request.auth != null` 로 좁히는 것이 가장 적은 노력으로 크게 나아지는 방법입니다.
점수 위조까지 막으려면 Cloud Functions에서 점수를 계산해야 하고, 이때는 Blaze 요금제가 필요합니다.

## 5. 파일 구조

```
index.html              모든 화면의 마크업
css/app.css             분수 표기 · 풀이판 · 세로셈 격자 스타일
js/firebase-config.js   Firebase 설정 (직접 채우는 파일)
js/fraction.js          분수 코어 (약분 · 사칙연산 · 대분수 변환 · 파싱)
js/levels.js            레벨 정의 · 잠금 규칙 · 점수 계산
js/generator.js         레벨별 문제 생성 + 4지선다 오답 보기
js/db.js                Firestore / localStorage 데이터 계층
js/session.js           연습 세션 공통 (타이머 · 결과 화면 · 저장)
js/step-frac.js         분수 단계 풀이 엔진
js/step-int.js          정수 세로셈 엔진 (곱셈 · 나눗셈)
js/quiz.js              4지선다 엔진
js/app.js               화면 전환 · 레벨 목록 · 교사 대시보드
tools/pin-hash.html     PIN 해시 생성기
firestore.rules         Firestore 보안 규칙
```
